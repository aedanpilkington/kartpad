# X draft — September 10 releases

Draft only; no X post was sent by the release task.

## Main post

New KartPad builds for Android, iPhone/iPad and Mac! Android gets smoother menu rendering, a refreshed chooser and Retro update save protection. iPhone/iPad gets reviewed-log reporting; Mac gets a graphics-view fix. Downloads: https://github.com/chrissotraidis/kartpad#downloads

## Measurement reply

Local Pixel 9 Pro XL tests at 2x/Fill: warm GP-menu FPS rose from 40–50 to about 58 with the rendering change enabled. A stationary Retro scene rose from 51–54 to 55–56 FPS. Menu delays and GPU issues remain; this is not an across-phone speedup claim.

## Longer release note

KartPad's latest Android, iPhone/iPad and Mac builds are now available. Android
adds a refreshed chooser, rendering improvements, better problem reports and
save protection when updating Retro Rewind. Our clearest measured gain is
smoother motion in the tested Android menu; race gains were smaller and menu
transitions still need work. iPhone/iPad now shows the log for review and asks
for acknowledgment or an explanation if it cannot be attached. The Mac update
includes a Metal graphics-view ownership fix. All releases include notices and
checksums, with a shared source bundle and reconstruction instructions.
