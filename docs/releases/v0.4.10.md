# KartPad 0.4.10 — iPhone and iPad build 25

- iPad touch defaults now match the layout edited and tested by the maintainer.
  Existing custom layouts and iPhone defaults are preserved.
- **Return to KartPad Menu** pauses the running game and opens the chooser.
  **Resume** continues that session. Switching games requires choosing **Use on
  Next Launch**, fully closing KartPad from the app switcher, and reopening it.
- **Player Identity → Rename or Delete Licenses…** identifies each game profile
  and slot. Deleting one slot leaves other licenses in place.
- **Edit Mii Name…** distinguishes Mii identity from a game license. Create a
  license with **New** inside the game, then select your Mii.
- Pending identity edits explicitly require fully closing and reopening the
  app. Returning to its menu and resuming does not apply them. Confirmation
  alerts wait for the previous dialog to dismiss.
- Original Mario Kart Wii no longer offers unusable private friend-room
  instructions. Experimental server settings require an already-running
  compatible Wii service. Retro Rewind retains Retro WFC friend-room guidance.

Native MeleePad-style private rooms and in-process game switching remain open.
Production online race acceptance remains separate. Retro Rewind stays pinned
to 6.12.7. This IPA updates iPhone/iPad; Mac and experimental Apple TV downloads
remain at 0.4.9. Android development remains paused.

The IPA is unsigned and requires local re-signing and a user-supplied supported
PAL RMCP01 revision 0 game image. It includes ahead-of-time translated game logic,
but no disc image, extracted game assets, Retro Rewind pack, saves, signing
identity, or provisioning profile.
